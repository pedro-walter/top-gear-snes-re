# Big menu font glyphs

16x16 RGBA PNGs (transparent background, the game's gold palette, 15 colours + transparent), one per glyph.

* `original/` - the game's own glyphs: A-Z, `1`, `2`, arrows. It has no 0 (the O is used), 3-9 (5 = S, 8 = B).
* `current/` - the hex digits our `tools/bigfont.py` draws (0-9, A, b, C, d, E, F) for the keypad.
* `scaled/` - original glyphs at 10x for viewing. `sheet_original.png`, `sheet_current.png` - overview sheets (4x).
